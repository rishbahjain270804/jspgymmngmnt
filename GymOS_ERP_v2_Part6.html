GymOS ERP v2 — Part 6

Design System • Component Library • UI Specification • Design Tokens

1. Design Philosophy

  • Mobile-first, desktop-optimized.
  • One primary action per screen.
  • Consistent spacing, typography and hierarchy.
  • AI suggestions assist users without blocking workflows.
  • Role-aware interfaces: users only see what they need.

6. Mobile Design Rules

Navigation

Bottom navigation with 5 items maximum.

Cards

Single-column responsive layout.

Actions

Primary CTA fixed at bottom when appropriate.

Search

Always available on operational screens.

Performance

Target <2 second interaction time.

Offline

Queue attendance and payments until online.

7. Accessibility Standards

  • WCAG AA contrast compliance.
  • Keyboard navigation on desktop.
  • 44px minimum touch targets.
  • Visible focus states.
  • Screen-reader labels for controls.
  • No color-only status indicators.
