5. Audit Strategy

  • Every create/update/delete operation writes an immutable audit record.
  • Store user_id, branch_id, organization_id, IP, device, timestamp.
  • Before/after JSON snapshots for sensitive records.
  • No hard delete for financial data.
  • Soft delete with archived_at for operational entities.

7. Database Standards

  • UUID primary keys.
  • created_at / updated_at on all tables.
  • organization_id on tenant tables.
  • branch_id where applicable.
  • JSONB for AI metadata.
  • Timezone-aware timestamps.
