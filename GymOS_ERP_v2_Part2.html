7. Wireframe Principles

  • One primary action per screen.
  • Phone number is the primary search key.
  • Status colors reserved for membership state only.
  • Desktop optimized for operations.
  • Mobile optimized for execution.
  • Persistent global search.
  • AI suggestions visible but non-blocking.
