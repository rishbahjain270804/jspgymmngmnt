# Localhost Setup Plan — OAN Gym

## Goal
Get the project running on localhost with MySQL on port 3307 and phpMyAdmin on port 8080.

## Steps

### 1. Add phpMyAdmin to docker-compose.yml
Add a `phpmyadmin` service to `docker-compose.yml` that:
- Uses `phpmyadmin/phpmyadmin:latest`
- Sets `PMA_HOST: db` and `PMA_PORT: 3306`
- Maps port `8080:80`
- Depends on `db` service with `condition: service_healthy`
- Uses `restart: unless-stopped`

### 2. Create `.env` file for the API
Create `apps/api/.env` with:
```
DB_HOST=127.0.0.1
DB_PORT=3307
DB_USER=oan
DB_PASSWORD=oan_dev
DB_NAME=oan
```

### 3. Start Docker services
Run `docker compose up -d` from the project root to start MySQL and phpMyAdmin.

### 4. Install dependencies
Run `pnpm install` from the project root.

### 5. Run database migrations
Run `pnpm --filter @oan/api migrate` or execute the migration script to set up the schema.

### 6. Start the API
Run `pnpm --filter @oan/api build` then `node apps/api/dist/index.js` (or the appropriate entry point).

## Verification
- MySQL should be accessible at `127.0.0.1:3307`
- phpMyAdmin should be accessible at `http://localhost:8080`
- API should be running on its configured port

## Notes
- The docker-compose.yml already has MySQL configured on port 3307 with user `oan` / password `oan_dev` / database `oan`
- The API's `connect.ts` defaults to `DB_HOST=127.0.0.1`, `DB_PORT=3307`, `DB_USER=oan`, `DB_PASSWORD=oan_dev`, `DB_NAME=oan`
- The `apps/api/db/init/01-test-grants.sql` script runs on first container start
